# Security Policy

## Reporting a vulnerability

Please **do not report security vulnerabilities in public issues**.

Report them privately through GitHub: open the [Security tab](https://github.com/Hejnas/hejnas-tripod-sensor/security) of this repository and click **Report a vulnerability**. Only the maintainer can see the report.

Please include a description of the problem, the steps to reproduce it and its possible impact.

## Supported versions

There are no releases yet. Security fixes are made on the latest `main`.
